# 阿里雲 OSS 同步儲存

將 Tau 的筆記、對話與附件同步至阿里雲 OSS。更換電腦或在電腦與手機之間切換時，都能取得同一份資料庫資料。私人 Bucket 也可直接使用，無須開放公開存取。

## 開始使用

1. 在外掛中心安裝「阿里雲 OSS 同步儲存」，再到外掛頁的「已安裝」裡開啟開關。
2. 開啟外掛詳情的「設定」。
3. 填寫「AccessKey ID」、「AccessKey Secret」、「Bucket」與「區域」（例如 `oss-cn-hangzhou`）；「目錄」留空即使用根目錄。
4. 儲存並測試連線後，前往「設定 → 同步」選用此服務，即可檢查狀態、上傳、下載或開啟自動同步。儲存設定不會自動切換目前使用的同步服務。

## 常見問題

**提示權限不足或網路錯誤？** 請檢查 AccessKey 是否具備此 Bucket 的讀寫權限、「區域」是否填寫正確，修正後重試即可。

**提示 Bucket 的版本設定不相容？** 請前往阿里雲控制台檢查該 Bucket 的版本控制設定。為避免覆蓋你的資料，遇到衝突時同步會自動停止，不會強行寫入。

**可以和其他資料庫共用同一個儲存位置嗎？** 不要。請為每個資料庫使用獨立的儲存位置（可透過「目錄」區分），否則資料會互相覆蓋。

**停用外掛會刪除資料嗎？** 不會。你的設定與已同步的資料都會保留，重新啟用就能繼續使用。正在同步期間無法停用或解除安裝外掛，請待同步完成後再操作。

## 小提醒

- 支援電腦與手機；如果同時安裝了資源上傳外掛，兩邊的帳號分開填寫，互不影響。
- AccessKey 等同於帳號的鑰匙，不要發給別人，也不要貼在截圖或問題描述裡。
