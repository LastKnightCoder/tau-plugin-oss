# 阿里云 OSS 同步存储

把 Tau 的笔记、对话和附件同步到阿里云 OSS。换电脑或在电脑与手机之间切换时，都能拿到同一份资料库数据。私有存储桶也能直接用，不需要开放公开访问。

## 开始使用

1. 在插件中心安装「阿里云 OSS 同步存储」，再到插件页的「已安装」里打开开关。
2. 打开插件详情的「设置」。
3. 填写「AccessKey ID」、「AccessKey Secret」、「Bucket」和「区域」（比如 `oss-cn-hangzhou`）；「目录」留空即使用根目录。
4. 保存并测试连接后，到「设置 → 同步」选用此服务，即可检查状态、上传、下载或开启自动同步。保存配置不会自动切换当前同步服务。

## 常见问题

**提示权限不足或网络错误？** 检查 AccessKey 是否有这个存储桶的读写权限、「区域」是否填对，修正后重试即可。

**提示存储桶的版本设置不兼容？** 请到阿里云控制台检查这个存储桶的版本控制设置。为了不覆盖你的数据，遇到冲突时同步会停下来，不会强行写入。

**能和别的资料库共用同一个位置吗？** 不要。每个资料库请使用单独的存储位置（可以用「目录」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 支持电脑与手机；如果同时装了资源上传插件，两边的账号分开填写，互不影响。
- AccessKey 相当于账号的钥匙，不要发给别人，也不要贴在截图或问题描述里。
