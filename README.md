# 阿里云 OSS 同步存储

把 Tau 的笔记、对话、附件同步到阿里云 OSS。换电脑或多台设备之间，都能拿到同一份数据。私有存储桶也能用，不需要开放公开访问。

## 开始使用

1. 在插件中心安装「阿里云 OSS 同步存储」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开「设置 → 同步」，选择「同步插件」里的「阿里云 OSS 同步存储」。
3. 填写存储桶（Bucket）、地域（比如 oss-cn-hangzhou）和 AccessKey；路径前缀保留 / 即可。
4. 保存后，就可以用检查、上传、下载和自动同步了，用法和其他同步方式一样。

以前在 Tau 里配过 OSS 同步的话，配置会自动带过来，不用重新填写。

## 常见问题

**提示权限不足或网络错误？** 检查 AccessKey 是否有这个存储桶的读写权限、地域是否填对，修正后重试即可。

**提示存储桶的版本设置不兼容？** 请到阿里云控制台检查这个存储桶的版本控制设置。为了不覆盖你的数据，遇到冲突时同步会停下来，不会强行写入。

**能和别的知识库共用同一个位置吗？** 不要。每个知识库请用单独的存储位置（可以用「路径前缀」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- AccessKey 相当于账号的钥匙，不要发给别人，也不要贴在截图或问题描述里。
